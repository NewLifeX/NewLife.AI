# NewLife.AI 功能清单

> 版本：v1.2 | 日期：2026-07-18

> 状态标记：✅ 已完成 | 🟡 部分完成 | 🔧 规划中 | ⏸ 暂缓/占位 | ❌ 未开始 | ❓ 待确认 | — 不适用

**拆分规则**：前后端拆为独立功能点，多平台拆为独立功能点。每个功能点保持 3 维状态（实现/测试/注释）。

**编码方案**：字母前缀 + 数字后缀，与 StarChat 商用版共用模块编码体系。社区版不包含 KNOW、PROJ、DESK 模块。

| 编码 | 模块 | 对应工程 | 说明 |
|:----:|------|----------|------|
| **AI** | AI Client SDK | `NewLife.AI` | 模型服务商、协议适配、多模态、Embedding 等底层能力 |
| **CHAT** | 对话系统 | `NewLife.ChatAI` + `NAI/Web` | WebUI 对话、会话管理、消息展示、多模态交互 |
| **TOOL** | 能力扩展（实现层） | `NewLife.AI` + `NewLife.ChatAI` | 技能、原生工具实现、MCP 实现、Filter 实现、注入策略、数据库工具、可视化（接口见 AI） |
| **EVO** | 知识进化（基础版） | `NewLife.ChatAI` | 用户记忆 10 类自动提取与注入 |
| **GW** | API 网关 | `NewLife.ChatAI` | 多协议入站、AppKey、模型路由、用量记录 |
| **IM** | 渠道集成 | `NewLife.AI` + `NewLife.ChatAI` | 钉钉/企微/飞书/Webhook/Slack/Telegram |
| **AGENT** | 智能体框架 | `NewLife.AI` | Planner、多 Agent、反思、HITL |

> ⚠️ 本清单仅列出社区版（NewLife.AI + NewLife.ChatAI）功能。商用版 StarChat 额外包含 KNOW（知识库）、PROJ（项目运营）、DESK（桌面客户端）及各模块高级子功能。
